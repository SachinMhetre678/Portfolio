# Architecture

Updated 2026-10-10. Next.js 13.5 (Pages Router), React 18, TypeScript, Tailwind 3. Path alias `@/*` points to `src/*`.

## Routes

| Route | File | Notes |
|---|---|---|
| `/` | `src/pages/index.tsx` | Renders `modules/home` |
| `/about` | `src/pages/about.tsx` | `getStaticProps` passes `hasResume` |
| `/projects` | `src/pages/projects/index.tsx` | Category filter in the URL (`?category=`) |
| `/contact` | `src/pages/contact.tsx` | `getStaticProps` passes `hasResume` |
| 404 | `src/pages/404.tsx` | |

`_app.tsx` sets up fonts, `DefaultSeo` (from `common/constant/site.ts`), `ThemeProvider`, `Layout` and `MascotLoader`. There are no API routes.

## Folders and components

- `src/modules/home/components/`: `Home.tsx` lists the sections in order: `Hero`, `ProofStrip`, `AboutBlock`, `SelectedWork`, `StackRack`, `Closing` (all except `Hero` and `StackRack` are in `Sections.tsx`). `RoutingMockup.tsx` is the fake dashboard used on the failure-management card.
- `StackRack.tsx`: the "My stack" section. Heading, avatar and the `UNITS` array (rack groups and items) are constants at the top. Each item names an SVG in `public/icons/stack/`. Single-colour logos (`mono: true`) are drawn with a CSS mask on a light plate. Rack styles are the `.rack-*` classes in `globals.css`.
- `src/modules/projects/components/`: `Projects.tsx` (page, filter, card order), `WorkCard.tsx` (card, and which visual each project gets), `PosterVisual.tsx` (cropped poster button plus a native `<dialog>` modal with Esc, focus handling and a Close button, captioned "Project poster"), `EarlierWorkList.tsx`.
- `src/modules/about`, `src/modules/contact`: page components. Their data is in `src/common/constant/` (`about.ts`, `contact.tsx`).
- `src/common/components/layouts/`: `index.tsx` (skip link, `PillNav`, `<main id="main">`, `Footer`, Vercel Analytics and Speed Insights), `PillNav.tsx` (floating nav on every page), `Footer.tsx`.
- `src/common/components/elements/`: shared pieces such as `Portrait` (arch hero portrait), `PageHeader` (badge and two-tone headline), `PillLink`, `Chip`, `ThemeToggle`, `Image` (thin `next/image` wrapper), `Container`.
- `src/common/components/mascot/`: Strobi. `MascotLoader.tsx` loads `Mascot.tsx` with `next/dynamic` (no SSR) once the browser is idle. `strobiLines.ts` holds every line. `useBubble.ts` is the speech-bubble engine (cooldown, one at a time), `useStrobiVoice.ts` the triggers (hover, scroll, idle, easter eggs), `useStrobiAvatar.ts` the avatar (`@bible-strong/avatar-web`) and its animations, `useAvoidOverlap.ts` the phone overlap rules, `Bubble.tsx` the bubble and quick menu (Shh, Unmute), `storage.ts` the localStorage and sessionStorage keys. The avatar definition is `public/strobi.avatar.json`, fetched at runtime.
- `src/common/libs/`: `cn.ts` (clsx + tailwind-merge), `motion.ts` (reveal helpers), `resume.ts` (checks for `public/resume.pdf` at build time).

Strobi is wired to the page by `data-strobi` and `data-strobi-section` attributes, and `data-mascot-avoid` marks things it should not cover on phones.

## Theming

`next-themes` adds a `dark` class on `<html>` (default dark, system theme off). Colors are CSS variables in `src/common/styles/globals.css` (`:root` for light, `.dark` for dark), exposed to Tailwind as semantic names (`bg-canvas`, `text-ink`, `border-hairline`, `text-accent`) in `tailwind.config.js`. Light mode gets warm paper tones through `.home-shell`, which wraps every page. Token values and rules are in `docs/DESIGN_SYSTEM.md`.

## Fonts

`geist` provides Geist Sans and Geist Mono (`next/font`, self-hosted, set as `--font-sans` and `--font-mono` in `_app.tsx`). `common/fonts.ts` adds Geist Italic (`next/font/local`, for two-tone headlines) and Caveat (`next/font/google`, downloaded at build time, for one handwritten note). `geist` is listed in `transpilePackages`.

## Images and icons

- Photos and posters are in `public/images/` and rendered with `next/image` (`Image` wrapper), so Next resizes and serves optimized sizes. Posters are WebP in `public/images/projects/`; the portrait is `sachin-portrait.jpg`.
- The My stack avatar is `public/images/sachin-3d-pointing.webp`, generated from the original PNG. Originals are kept in `docs/source-images/` and are never deleted.
- Stack logos are SVG files in `public/icons/stack/`, copied from devicon (MIT) and simple-icons (CC0). Sources per icon are in `docs/DESIGN_SYSTEM.md` section 10.
- UI icons come from `react-icons/pi` (Phosphor).
- `public/og.png` is the Open Graph image. `robots.txt` and `sitemap.xml` are generated by `next-sitemap` after a build.

## Run, build, deploy

- Requires Node.js 22.12 or newer (the mascot packages) and npm.
- `npm run dev`, `npm run build` (runs `next build`, then `next-sitemap`), `npm run start`, `npm run lint`, `npm run typecheck`.
- Never run `build` while `dev` is running: both write `.next`. If it breaks, stop both and remove `.next`.
- The build prints an ESLint parser warning (`@babel/eslint-parser` is named in `.eslintrc` but not installed). See `docs/TODO.md`.
- Vercel deploys `main` to production and other branches to previews, using Node.js 24.x (set in the Vercel project, not in the repo). `vercel.json` uses `@vercel/next`. `SITE_URL` can override the sitemap host.
